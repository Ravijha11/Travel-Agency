# Lahar connect

Coordination-only ride sharing directory for trips between Lahar and Gwalior.

## Quick start

```bash
npm install
npm run dev
```

Required environment variables:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
